# AuPortableDocEditor

独立 PDF 页面编辑器，专注于**页级编辑**：打开 PDF 后可以插入空白页、
删除页、用另一个 PDF 的页面替换当前页，然后整体重写保存。

本工程完全独立，不依赖仓库中其它组件，可单独拷出构建。

## 功能

- **打开 PDF**：菜单 / 工具栏 / 命令行参数 / 直接拖拽 PDF 文件进窗口
- **页面平铺预览**：页面按真实内容渲染成缩略图平铺显示（左到右自动换行），
  窗口宽时每行显示更多页，窄时按缩略图宽度自适应换行；
  每项下方标注页号与页面尺寸（pt）
- **拖动排序**：直接拖动缩略图调整页面顺序，
  拖动过程中用高亮竖线实时标示插入位置（自身页前后不会误显示），
  半透明快照跟随光标、原位置保持不动，松手即落位，按 `Esc` 取消
- **旋转页面**：工具栏/菜单可选左转 90°、右转 90°、旋转 180°，
  只写入 PDF 标准的 /Rotate 属性，内容无损；缩略图即时同步旋转
- **插入空白页**：「插入空白页」按钮可选 *在所选页之前*（`Alt+1`）/
  *在所选页之后*（`Alt+2`），新页尺寸优先继承前一页
  （其次后一页，最后 A4），呈现为纯白空页
- **删除页**：删除所选页（`Alt+Delete` 或 `Delete`，
  不允许删掉文档的全部页面）
- **替换页**：选择另一个 PDF 文件，从中挑选一页（附内容预览）深拷贝换入，
  保留被换入页的原始内容、矢量图形与文字
- **保存 / 另存为**：`Ctrl+S` 直接保存，`Ctrl+Shift+S` 另存；
  保存采用原子写入（`QSaveFile`），不会损坏原文件
- 未保存修改时标题栏带 `*`，关闭窗口前会提示保存

## 构建与运行

### CMake（Qt 5.6+ / Qt6）

```bash
cd AuPortableDocEditor
cmake -B build -S .        # 需要能找到 Qt（必要时加 -DCMAKE_PREFIX_PATH=<Qt目录>）
cmake --build build
```

### qmake

```bash
cd AuPortableDocEditor
qmake AuPortableDocEditor.pro
make        # Windows/MinGW: mingw32-make；MSVC: nmake 或 jom
```

仓库根目录下两套构建系统均已注册本工程，全仓构建时无需额外步骤。

### 关于页面预览

页面缩略图按以下顺序自动选择渲染后端，无需任何构建配置：

1. **QtPdf 模块**（Qt6 且安装了 QtPdf 时编译启用）
2. **pdfium 动态库**（运行时经 `QLibrary` 加载，无链接期依赖）：
   Windows 下使用仓库内自带的 `third_party/pdfium/pdfium.dll`（构建脚本
   自动拷贝到程序目录，来源与许可见 `third_party/pdfium/README.md`）；
   Linux 需自备 `libpdfium.so` 放到程序目录。缺失时状态栏会提示，
   缩略图退回绘制的占位页图标（页号与功能不受影响）

pdfium 与 Chrome 使用同一渲染引擎，矢量、文字、图像均可真实呈现，
且两种后端都不修改被预览的文件。

## 实现说明

Qt 自带的 `QPdfDocument` 只能读取和渲染，不支持修改文档，因此本工程
自带一个轻量 PDF 编辑引擎（`src/pdf/`，仅依赖 QtCore），思路是**只做
页级手术、不碰页内容**：

- **装载**：解析交叉引用链（经典 xref 表 / PDF 1.5+ xref 流 / 混合 XRefStm），
  对象流（ObjStm）解压后平铺为常规对象；装载时把页树展开为单层
  Kids 数组，并把 MediaBox / CropBox / Resources / Rotate 等继承属性
  下拷到每一页，之后的增删改都是对页数组的简单操作。
- **替换页**：从源文档深拷贝被选页的可达对象子树（内容流、字体、
  图像、注释等），自动重编号并去重。
- **保存**：mark-sweep 清理被删页 / 被换页遗留的孤儿对象并紧凑重编号，
  重建单层页树，输出经典 xref 表（兼容性最好），保留原 PDF 版本号，
  并更新文档的修改时间。

## 已知限制

- **不支持加密 PDF**（打开时报错）
- 不支持页内容级编辑（文字 / 图片修改），只做页级操作
- 损坏严重的 PDF 走修复模式装载，个别极端文件可能仍无法打开
- 超大文件（数百 MB 以上）装载与保存耗时较长
