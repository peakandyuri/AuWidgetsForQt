# AuSnipping

一个用纯 QWidget 实现的独立截图小工具，主要面向银河麒麟（UKUI / X11）等缺少称手
截图工具的 Linux 环境，同时兼容 Windows。本工程**完全独立**，不依赖本仓库其它
组件，可单独把 `AuSnipping/` 目录拷出构建。

## 功能

- **三种截图模式**（主界面单选，按“开始截图”或快捷键触发）
  - 全屏截图：直接把整个屏幕复制进剪贴板
  - 区域截图：屏幕蒙半透明遮罩，拖动框选；选区内部完全透明（即截图内容），
    四周/四角可调整大小，框内可拖动整框；框附近实时显示宽×高
    （位置自适应：框外上方 → 框内 → 框下方 → 框内，横向越界自动收进屏幕）
  - 窗口截图：自动捕获光标下的原生顶层窗口并高亮，点击确认，不可调整大小
- **连续截图**：区域 / 窗口截图确认后进入编辑，编辑窗口里有「继续截图」按钮，
  点击后不退出编辑流程、直接回到上一个截图界面（冻结画面与选区保持不变，
  当前画面含标注已实时同步在剪贴板，不会弹保存询问），可继续调整选区再次
  截图；全屏模式下「继续截图」直接开始下一张全屏截图。关闭编辑窗口同样会
  回到截图界面；按 `Esc` / 右键取消才结束本次会话回到主界面。
  编辑窗口打开期间快捷键不开启新截图（会把编辑窗口带到前台）
- **开始截图快捷键**：默认 `Alt+S`，可自定义；支持全局生效
  （Windows 用 RegisterHotKey，X11 用 XGrabKey，任何应用前台都能触发；
  Wayland 下自动退化为仅窗口内生效）；触发截图前会先把主窗口设为全透明
  并等待其完全隐藏，不会把半透明残影截进画面
- **延迟截图**：0（无）~ 5 秒，倒计时期间可正常操作其它应用
- **光标捕获**：可选；光标图像在截图触发瞬间抓取，保证样式与启动时一致
- **剪贴板**：截图完成后自动写入内存剪贴板
- **立即保存**（可选）：开启后不弹编辑窗口，直接保存到当前用户图片目录
  （`QStandardPaths::PicturesLocation`），文件名按当前时间（`20261007_153012.png`），
  并发送一条桌面通知（Linux 走 D-Bus `org.freedesktop.Notifications`，
  回退托运气泡；Windows 走托运气泡）
- **标注编辑**（默认）：截图后弹出编辑窗口，内置简易画板：
  - 画笔、文字、矩形框、椭圆、直线
  - 颜色（8 色快选 + 自定义）、线条粗细（1~20）、文字字号（8~96）
  - 撤销 / 恢复 50 步：`Ctrl+Z` 撤销，`Ctrl+Shift+Z`（或 `Ctrl+Y`）恢复，
    与麒麟/Linux 习惯一致，同时兼容 Windows 习惯
  - 每次标注变化都会实时同步到剪贴板
  - 保存：可自定义目录（默认记住上一次选择的目录），文件名默认为截图时间，
    支持 PNG / JPEG；关闭前有未保存标注会询问

## 构建

依赖：Qt 5.10+（建议 5.12，兼容 Qt 6）、Core/Gui/Widgets。

Linux 下可选依赖（用于窗口截图与光标捕获，缺失时自动降级，不影响编译运行）：
- Xlib（`libx11-dev`，经 pkg-config `x11` 检测）
- XFixes 运行库（桌面系统均自带，运行期 dlopen 加载，构建无需 dev 包）
- QtDBus（Linux 发行版 Qt 默认自带，用于桌面通知）

### qmake

```bash
cd AuSnipping
qmake AuSnipping.pro
make            # Windows: mingw32-make / nmake / jom
```

### CMake

```bash
cd AuSnipping
cmake -B build -S . [-DCMAKE_PREFIX_PATH=/path/to/Qt]
cmake --build build
```

## 使用

不带参数启动显示主界面，单选截图模式后按“开始截图”或快捷键（默认 `Alt+S`）：

| 快捷键 / 操作 | 行为 |
| --- | --- |
| `Alt+S`（可改） | 开始截图（可勾选“全局生效”，任何应用前台均可触发） |
| 按住左键拖动 | 框选截图区域 |
| 框内拖动 | 移动选区 |
| 边框 / 四角拖动 | 调整选区大小 |
| Enter / 双击 / “确定” | 确认截图 |
| Esc / 右键 / “取消” | 取消截图（会话中按 Esc 结束连续截图，回主界面） |
| 窗口模式下点击 | 截取高亮的窗口 |
| 编辑窗口关闭后 | 自动回到上一个截图界面（选区保留），可继续截图 |
| 编辑窗「继续截图」按钮 | 不退出流程直接回到截图界面（全屏模式则直接截下一张） |
| `Ctrl+Z` | 编辑器撤销 |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 编辑器恢复 |

### 命令行

```bash
AuSnipping --fullscreen   # 启动后立即全屏截图
AuSnipping --region       # 启动后立即区域截图
AuSnipping --window       # 启动后立即窗口截图
AuSnipping --selftest     # 运行无头自检后退出
```

`--fullscreen` 等模式参数非常适合绑定系统快捷键（麒麟：系统设置 → 键盘 →
自定义快捷键，命令填 `AuSnipping --region`），延迟与光标等选项沿用上次
在主界面的设置；程序内置的全局快捷键（默认 `Alt+S`）无需系统设置即可全局触发。

## 平台说明与限制

- 窗口截图与光标捕获依赖 X11：麒麟 V10（UKUI，X11 会话）下全功能可用。
  Windows 使用 Win32 API（EnumWindows + DWM 扩展边框，dwmapi 运行期动态
  加载）实现。
- Wayland 会话下自动降级：窗口检测仅能识别 Qt 应用窗口，光标捕获不可用，
  其余功能正常。
- 多显示器时抓取光标所在的屏幕；虚拟桌面统一 DPI（非混合 DPI）下坐标精确。
- 截图为“冻结快照”：遮罩层显示的是触发瞬间的画面，期间屏幕内容变化不影响
  截图结果。

## 目录结构

```
AuSnipping/
├── AuSnipping.pro          # qmake 工程
├── CMakeLists.txt          # CMake 工程
└── src/
    ├── Main.cpp            # 入口与命令行、自检
    ├── Launcher.*          # 主界面：模式与选项、倒计时、流程调度
    ├── Capturer.*          # 抓屏、原生窗口检测、光标捕获（Win/X11/兜底）
    ├── GlobalHotkey.*      # 全局热键（Win RegisterHotKey / X11 XGrabKey）
    ├── SnipOverlay.*       # 全屏遮罩层：区域框选 / 窗口高亮
    ├── AnnotationCanvas.*  # 标注画板（画笔/文字/矩形/椭圆/直线、撤销恢复）
    ├── EditWindow.*        # 截图编辑窗口（保存/复制/剪贴板同步）
    ├── Settings.*          # 设置持久化
    └── Notifier.*          # 桌面通知
```

> 源码文件采用 PascalCase（帕斯卡命名法）命名，与其中类名保持一致。
